Модель вотчлиста и действия

Вотчлист — сущность уровнем выше доски: бумаги, рутины по ним, их отчёты, общий каскад и его итог. Колонок три или четыре: «Сводная обработка» появляется, только если у рутин есть общий обработчик. «Результат» всегда последний. Связи — как на проде. В API уже есть раздел досок section=watchlist.
