# Вотчлист · roadmap каскада

Прототип вотчлиста Finam X по доске 8968 «Начни утро с обзора рынка», вариант «с каскадом — 4 колонки». Канвас «Вотчлист · roadmap каскада», v27, 30.09.2026.

`index.html` — сам прототип. Открывается по ссылке GitHub Pages или двойным кликом.

- `source/` — файлы канваса без изменений: все артборды `*.dc.html` и `canvas.json`.
- `build.py` — пересобирает `index.html` из `source/Main.dc.html`.
- `assets/` — рантайм для артборда (`dc-lite.js`), React 18.3.1 (MIT) и аватар из сайдбара.

Обновить: положить новые файлы канваса в `source/`, запустить `python3 build.py`, закоммитить.
